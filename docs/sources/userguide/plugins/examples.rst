.. _plugin-dependent-examples:

Plugin examples
===============

The SpectroChemPy gallery includes examples for several optional plugins.
For the plugin and namespace used by each example, see the
:ref:`plugin examples list <plugin-examples-list>`.

NMR examples for importing, processing and analyzing spectra are in the
`NMR plugin gallery <https://www.spectrochempy.fr/projects/nmr/latest/examples_overview.html>`_.
Install the :doc:`required plugin <official_plugins>` before running an example.
