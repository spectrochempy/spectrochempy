Apodization
===========

For NMR apodization, see the plugin's
`apodization examples <https://www.spectrochempy.fr/projects/nmr/latest/examples/gallery/apodization/index.html>`_
and `1D processing guide <https://www.spectrochempy.fr/projects/nmr/latest/userguide/processing_1d.html>`_.

The core supplies exponential (:func:`~spectrochempy.em`),
Gaussian (:func:`~spectrochempy.gm`), and sine-bell
(:func:`~spectrochempy.sp`) windows for time-domain datasets.
