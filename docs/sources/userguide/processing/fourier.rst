Fourier transformation
======================

For NMR data, follow the plugin's
`1D processing guide <https://spectrochempy-nmr.readthedocs.io/latest/userguide/processing_1d.html>`_
and `2D processing guide <https://spectrochempy-nmr.readthedocs.io/latest/userguide/processing_2d.html>`_.

The core provides :func:`~spectrochempy.fft` and :func:`~spectrochempy.ifft`
for datasets with calibrated coordinates. For FTIR interferograms, see
:doc:`interferogram`.
