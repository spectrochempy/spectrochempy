Coordinate-aware slicing
-------------------------
Using floats slices directly on axis coordinates instead of integer indices:

.. GENERATED FROM PYTHON SOURCE LINES 47-50

.. code-block:: Python

    carbonyl_region = dataset[:, 2300.0:1900.0]
    _ = carbonyl_region.plot()
